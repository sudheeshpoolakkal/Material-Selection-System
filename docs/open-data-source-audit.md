# Additional material databases — checked 2026-10-10

This is a discovery/access audit for Materia. No additional catalog rows were imported during this audit. The active catalog remains 21,663 records. Downloaded samples stay under the ignored `server/data/downloads/source-audit` directory; the checked-in `server/data/additional-sources-audit.json` records evidence, counts, checksums and adapter requirements.

TPSX is the strongest NASA candidate for the existing thermal-property workflow. Outgassing adds a new space-material screening capability. NIST cryogenic data is smaller, but its equations, conditions, uncertainty estimates and references can be more useful than a large collection of unqualified scalar values. Full JARVIS is a candidate to enrich existing crystal records, keeping computation separate from supplier/test data.

## Verified NASA examples and limitations

The TPSX list uses a public, legacy DataTables endpoint at `/database/`. A request with the standard pagination/sort/column parameters returned 1,549 total entries and a two-row sample. An initial request omitting required DataTables parameters returned HTTP 500; a complete request succeeded. This is a working table interface, not a claimed documented bulk export API.

The [sample composite record, TPSX ID 1547](https://tpsx.arc.nasa.gov/Material?id=1547), contains measured density **288 kg/m³**, through-thickness conductivity **0.107 W/m·K**, in-plane conductivity **0.199 W/m·K**, and specific heat **967 J/kg·K**. Each value has an uncertainty and a cited thermophysical report. Density conditions are marked assumed; conductivity conditions are marked standard. These details must survive an import. In-plane and through-thickness conductivity cannot become one interchangeable value in Materia. The sample property's modification dates are 2006; this is reference data with historical provenance.

The [NASA outgassing JSON](https://data.nasa.gov/docs/legacy/Outgassing_Db/Outgassing_Db_rows.json) downloaded successfully and parsed as 12,859 rows, all with the declared 18-column schema. SHA-256: `54338a86e1b50976a629fab54b0370b968493f57527fcf1e00f37a80ce1bd0db`. The raw snapshot is 2,944,719 bytes. TML appears in 12,858 rows, CVCM in 12,853 and WVR in 10,047; all non-null entries in these columns parse numerically. Cure information appears in 6,989 rows.

There are 12,848 unique sample IDs and 10,797 distinct material-name strings. Counts represent tests, not that many distinct qualified grades. A source sample ID alone is not a sufficient primary key: retain the stable source row identity and test/cure information. The downloaded file is the legacy tenth compilation, with embedded row timestamps from 2015. The catalog's later update date does not prove that the file is a current export of the live Goddard database.

Outgassing is measured using ASTM E595 according to the [current Goddard page](https://etd.gsfc.nasa.gov/capabilities/outgassing-database/). Those results do not supply tensile strength, elastic moduli or ordinary thermal conductivity. Add dedicated properties and constraints rather than treating these tests as mechanical or general corrosion evidence.

JARVIS [Figshare version 10](https://figshare.com/articles/dataset/jdft_3d-7-7-2018_json/6815699) explicitly listed CC BY 4.0 in the retrieved publisher index. The current article lists version 11, released 2026-05-09, and a 1.42 GB complete download. Requests for its current API/license metadata encountered certificate/fetch errors; certificate verification was not disabled. Reverify the selected version's license and file checksums before importing; do not assume that a software license covers every bundled dataset. The 75,993 count is from NIST's current dataset documentation, not a local row count.

The anonymous Materials Project build bucket returned `collections/`, `current-build/`, `images/` and `objects/` prefixes. This verifies a public retrieval path, not the licensing or completeness of every subcollection. Dataset versions and terms must be retained alongside the selected records.

## Sources that do not qualify as unrestricted bulk data

* [NASA MAPTIS](https://maptis.nasa.gov/Features) advertises over 32,000 materials in its selection list and includes extensive commercial databases. Its current notice says account cost-sharing/payment applies from January 2026. Registered access and third-party collections are distinct from an open public dataset.
* [NIMS MatNavi](https://mits.nims.go.jp/) includes useful PoLyInfo, Kinzoku, fatigue, creep and corrosion resources, but the publisher explicitly prohibits mass acquisition and web scraping. Free registered viewing is not a bulk-import permission. NIMS MDR is a separate repository that can be assessed dataset by dataset.
* [NIST Materials Data Repository](https://materialsdata.nist.gov/) is a discovery source for individual datasets. The repository states that providers define each entry's usage terms and that community records may not be critically reviewed. A blanket NIST/public-domain assumption is inappropriate.

## Import priority

1. **NASA TPSX:** implement a source-aware adapter that preserves measurement basis, units, uncertainty, direction, temperature curves and original references. Resolve the selected NASA/industry collection's data terms using its actual provenance.
2. **NIST cryogenic and Alloy Data:** prioritize conductivity, heat capacity and stiffness at known temperatures. Keep fit-derived values distinct from source measurements, and avoid extrapolating outside declared ranges. For example, the [6061-T6 table](https://trc.nist.gov/cryogenics/materials/6061%20Aluminum/6061_T6Aluminum_rev.htm) has different valid ranges and errors for conductivity, heat capacity and modulus; its linear-expansion values are not thermal-expansion coefficients.
3. **NASA Outgassing:** add dedicated vacuum-performance properties/constraints, then import the verified public-domain snapshot with stable row IDs and missing-value preservation.
4. **Full JARVIS and selected Materials Project products:** enrich the research collection with actual property-bearing records. Match source accessions and keep provenance so existing benchmark entries are not duplicated or silently blended with different calculations.
5. **NOMAD/Alexandria and permitted AFLOW subsets:** optional research expansion after the engineering-property gaps above are addressed.

Large database counts do not guarantee density, strength, conductivity, price and service limits for every entry. Useful expansion should be measured by property coverage and preserved conditions, with experimental, reference, fit-derived and computed values distinguishable.
